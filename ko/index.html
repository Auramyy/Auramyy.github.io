1.1 새 기능

어떤 휴대폰과도 공유, 그리고 새로운 Pro 테마 3종

어떤 휴대폰과도 공유

옆에 있는 iPhone이나 Android로 사진과 동영상을 원본 화질로 보내세요. 인터넷도, 계정도, 압축도 없습니다.

링크로 공유

내 Google 드라이브로 7일간 유효한 링크를 만드세요. 누구나 Auramy나 브라우저에서 원본을 내려받을 수 있습니다.

나와 공유된 항목

받은 항목은 모두 갤러리의 별도 카테고리에 모이고, 다른 항목처럼 드라이브에 백업됩니다.

Pro 테마 3종

티타늄, 에메랄드, 오로라가 아이콘까지 모든 화면을 새롭게 바꿉니다.

내 저장 공간 알기

사용 중인 공간과 남은 공간을 하나의 링으로 보여주고, 카메라 사진, 동영상, 스크린샷, 다운로드별로 나누어 보여줍니다. '사진' 앱이 어디에서도 보여주지 않는 파일별 실제 크기까지 확인할 수 있습니다.

  • 크기, 날짜, 유형별 정렬
  • '셀카 2024', '>100mb', '지난주' 같은 검색
  • 홈 화면의 '과거의 오늘' 추억

어떤 휴대폰과도, 원본 화질 그대로

근처에 공유는 iPhone이든 Android든 휴대폰에서 휴대폰으로 원본을 바로 보냅니다. 같은 Wi-Fi에서는 상대 휴대폰을 알아서 찾고, Wi-Fi가 없으면 코드를 스캔하는 것만으로 두 휴대폰이 바로 연결됩니다.

  • 원본 파일 그대로, Live Photo와 모션 포토 포함
  • 인터넷과 계정이 필요 없음
  • 원하면 보내기 전에 위치 정보 제거
  • 무료, 횟수 제한 없음

Wi-Fi가 없나요? 스캔하고 보내세요

받는 휴대폰이 코드를 보여주고, 보내는 휴대폰이 이를 스캔하면 전송이 시작됩니다. 주변에 네트워크가 없어도 Wi-Fi 속도로 전송됩니다. 멀리 있는 사람에게는 내 Google 드라이브에서 7일간 유효한 링크를 공유하세요.

  • iPhone과 Android 사이에서 작동
  • 링크는 Auramy나 어떤 브라우저에서도 열림
  • 언제든지 링크 공유 중단 가능

한 번의 탭으로 정리

딥 클린은 완전히 같은 사본, 거의 똑같은 연속 사진, 흐리거나 실수로 찍은 사진, 일회용 코드나 사용한 티켓 같은 다 쓴 스크린샷을 찾아내고, 연속 사진마다 가장 좋은 사진을 남깁니다.

  • 삭제 전에 모든 항목을 확인
  • 즐겨찾기는 절대 건드리지 않음
  • 삭제한 항목은 30일 동안 복구 가능
  • 완전히 같은 사본 정리는 무료

방해하지 않는 갤러리

카메라 사진, 동영상, 스크린샷, 다운로드, 나와 공유된 항목을 각각 스크롤할 수 있는 간단한 행으로 보여줍니다. '사진' 앱처럼 어떤 격자든 손가락으로 오므리고 벌려 확대할 수 있습니다.

  • 사진·동영상 편집기 내장
  • 카테고리 전체를 한 번의 탭으로 백업
  • 전용 PIN으로 잠그는 비공개 보관함

여섯 가지 스타일, 하나의 앱

라이트와 다크는 무료입니다. 네온, 티타늄, 에메랄드, 오로라는 Pro에 포함되며 아이콘까지 모든 화면을 새롭게 바꿉니다.

그리고 그 밖의 모든 것

내 Google 드라이브에 백업

원할 때 언제든 무료로 백업하고 복원하세요. Auramy는 'drive.file' 권한만 요청하므로 드라이브에서 자신이 만든 파일 외에는 아무것도 보지 못합니다.

안전하게 공간 확보

드라이브에 이미 안전하게 있는 항목을 휴대폰에서 제거합니다. 확인된 사본이 있는 항목만 대상입니다.

동영상은 작게, 추억은 그대로

4K 클립을 날짜와 위치를 그대로 유지한 채 1080p로 다시 인코딩합니다. 충분히 작아지지 않은 결과는 버립니다.

새 휴대폰으로 복원

같은 계정을 연결하면 백업에는 있고 휴대폰에는 없는 항목을 Auramy가 되돌려 놓습니다.

위젯과 단축어

저장 공간·사진 위젯, iPhone의 단축어와 제어 센터, Android의 빠른 설정 타일.

원할 때 잠금

앱 전체에 Face ID 또는 지문 잠금을 선택적으로 설정할 수 있습니다.

당신의 사진은 당신의 것

분석, 충돌 보고, 광고, Auramy 계정이 없습니다. 당신이나 보관함에 관한 어떤 정보도 개발자에게 전송되지 않습니다.

스캔, 중복 감지, 초점 확인은 모두 휴대폰에서 실행됩니다. 근처에 공유는 휴대폰에서 휴대폰으로 바로 전달되고, 공유 링크와 백업은 당신의 Google 드라이브에 있습니다.
