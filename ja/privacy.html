Auramy プライバシーポリシー

最終更新日：2026年10月14日

これは翻訳です。英語の原文と内容が異なる場合は、英語版が優先されます。

要点。Auramyにはサーバーがありません。写真、ビデオ、設定はあなたのスマホに残ります。開発者には何も送信されません。分析も、トラッキングも、広告も、アカウントもありません。データがデバイスの外に出るのは、あなたが求めたときだけです。つまり、あなた自身のGoogleドライブへのバックアップ、近くのスマホに直接送る写真、あなた自身のGoogleドライブからリンクで共有する写真です。

このポリシーは、Auramy（以下「本アプリ」）があなたの情報をどう扱うかを説明するものです。iPhone・iPad版（App Store）およびAndroid版（Google Play）のAuramyアプリと、auramyy.github.io/s/ の共有リンクページに適用されます。Auramyは Mustafa Yağız（以下「開発者」「私」）が開発・運営しています。

1. 開発者が収集する情報

ありません。Auramyにはサーバー側のサービスがありません。作成するアカウントも、データを受け取るサーバーもなく、開発者があなたの写真、ライブラリ、検索内容、共有したもの、アプリの使い方を見る手段もありません。

具体的に、Auramyは次のことを行いません。

  • あなたの写真やビデオを、開発者が運営するサーバーで収集・送信・保存すること
  • 分析、クラッシュレポート、広告、アトリビューションのSDKを組み込むこと
  • アプリやWebサイトをまたいであなたを追跡したり、プロファイルを作成したりすること
  • 個人情報を誰かに販売または共有すること

2. デバイスに残る情報

Auramyは次の情報をローカルに保存します。開発者がこれらを受け取ることはなく、アプリを削除するとすべて消去されます。

内容目的保存場所
ライブラリの検索インデックス（項目ID、メディアの種類、日付、ファイルサイズ、派生キーワード） ギャラリー検索をすぐに、オフラインでも使えるようにするため アプリ専用のストレージ
設定（テーマ、アプリロック、バックアップの設定、最近の検索） アプリの設定内容を覚えておくため アプリの設定（Auramyウィジェットと共有）
ドライブを接続した場合のGoogleアカウントのメールアドレス、およびiPhoneではアクセストークン 接続中のアカウントを表示し、サインイン状態を保つため iPhone：GoogleのSign-In SDKが管理するキーチェーン。Android：アプリの設定（トークンはGoogle Playサービスが保持）
プライベート保管庫に移した写真とビデオ（Pro） 保管庫のPINでしか開けないようにするため アプリ専用のストレージ（PINから導出した鍵で暗号化）
近くの端末と共有するときにこのスマホが表示する名前と、インストール時に作成されるランダムなID 相手のスマホに送信者を表示し、次回あなたのスマホを認識できるようにするため アプリの設定

共有したリンクの一覧と有効期限 リンクをコピー・停止でき、期限が来たら削除されるようにするため アプリ専用のストレージ
編集・書き出し・送信・受信するメディアの一時コピー 共有シート、エディタ、相手のスマホにファイルを渡すため システムの一時フォルダ（使用後に削除）

スマホ自体のバックアップ（iCloudまたはGoogle）には、他のアプリのデータと同様に、Auramyの設定と暗号化された保管庫が含まれる場合があります。そのコピーはあなたのAppleまたはGoogleアカウントに属し、開発者はアクセスできません。

3. Googleドライブへのバックアップ（任意）

AuramyはGoogleアカウントなしですべての機能が使えます。クラウドバックアップは任意です。オンにしてGoogleドライブを接続すると、次のようになります。

  • Auramyは選んだ写真とビデオを、あなた自身のGoogleドライブ内のAuramyという名前のフォルダにアップロードします。開発者はそのフォルダにも、あなたのドライブにもアクセスできません。
  • Auramyが求める権限は、範囲の狭い drive.file ひとつと、接続中のアカウントを表示するためのメールアドレスだけです。drive.file では、アプリは自分で作成したファイルだけを表示・管理できます。ドライブのそれ以外の内容は読めません。
  • 接続はGoogleが処理します。iPhoneとiPadではGoogle公式のSign-In SDK、AndroidではGoogle Playサービスです。AuramyがあなたのGoogleパスワードを見たり扱ったりすることはありません。
  • サインアウトすると、Auramyのアクセス権が取り消され、保存されたサインイン情報が削除され、何をバックアップ済みかというアプリの記録も消去されます。すでにドライブにあるファイルはそのまま残ります。それはあなたのものです。

Googleとの関係には、Google自身の規約とプライバシーポリシーが適用されます：policies.google.com/privacy。AuramyによるGoogle APIから受け取った情報の利用は、限定的使用の要件を含むGoogle API サービスのユーザーデータに関するポリシーに従います。

4. 写真とビデオの共有

共有はあなたが開始したときだけ、あなたが選んだ写真とビデオについてのみ行われます。開発者のサーバーを経由するものは何もありません。

近くの端末と、スマホからスマホへ

  • 2台のスマホは直接つながります。共通のWi-Fiネットワーク、どちらかが開く一時的なネットワーク、または端末同士の直接接続を使い、互いを見つけるためにBluetoothを使います。インターネット接続は使わず、どのサーバーも経由しません。
  • 接続はエンドツーエンドで暗号化されます。何かを送る前に、画面上のコードまたは読み取ったコードで2台が互いに通信していることを確認し、受信側のスマホは転送のたびに承認する必要があります。
  • 相手のスマホには、このスマホの名前（あなたが決め、変更可能）と、送られるものの一覧（ファイル名、サイズ、種類、撮影日）が表示されます。
  • 受信した写真は、他の写真と同じように写真ライブラリに保存されます。

リンクで、あなた自身のGoogleドライブ経由で

  • リンクで共有すると、Auramyは選んだ写真とビデオを、あなた自身のGoogleドライブ内のAuramy Sharesというフォルダ（バックアップとは別）にアップロードし、それらを説明する小さな一覧ファイル（スマホの名前、ファイル名、サイズ、種類、撮影日、チェックサム）も一緒に置きます。
  • これらのファイルはリンクを知っている全員が閲覧できる状態になります。写真を見てほしい人にだけリンクを共有してください。
  • リンクは7日後、Auramyがドライブからファイルを削除した時点で使えなくなります。「共有を停止」を選べばそれより前に止まります。その時点でAuramyがドライブに接続できない場合は、次にアプリを開いたときに再試行します。Auramy SharesフォルダはGoogleドライブで自分で削除することもできます。
  • 設定で「共有時に位置情報を削除」がオンの場合、共有ファイルから位置情報が削除されます。

リンクを開く

  • リンクを開くのにGoogleアカウントは不要です。AuramyアプリはGoogleドライブから直接ファイルをダウンロードし、一覧と照合したうえで写真ライブラリに保存します。
  • アプリがない場合、リンクは auramyy.github.io/s/ のWebページを開きます。このページは完全にブラウザ内で動作し、GoogleのDrive APIを通じてGoogleドライブから直接ファイルを読み込み、保存できるようにします。共有を識別するリンクの部分は # の後ろにあり、ブラウザはこの部分をWebサイトに送信しません。このページはCookieを使わず、分析も含まず、このサイトとGoogleドライブ以外からは何も読み込みません。

通信先

購入のためのApp StoreまたはGoogle Playを除き、Auramyが通信するのはGoogleのサーバーだけです。バックアップとリンク共有のための googleapis.com とGoogleのサインインページ、共有リンクとそのプレビューのダウンロードのための drive.usercontent.google.com と drive.google.com、そして近くの端末と共有している間は相手のスマホと直接通信します。それ以外の通信先はありません。

5. このWebサイト

このWebサイト auramyy.github.io はCookieを使わず、分析、広告、サードパーティのスクリプトも含みません。選んだ言語はあなたのブラウザのストレージに記憶され、デバイスの外に出ることはありません。サイトはGitHub Pagesでホストされており、他のWebホストと同様に、GitHubのプライバシーに関する声明に基づいてアクセスの技術的なログを保持する場合があります。

6. Auramyが求める権限

写真ライブラリ

アプリの中心的な目的のために必要です。ギャラリーの表示、削除できる重複や不要なものの検出、編集、選んだもののバックアップ、受信したものの保存に使います。Auramyは限定アクセスでも動作し、その場合は共有を許可した写真だけを扱います。写真の削除は必ずシステムを通して行われるため、システム自身の確認が表示されます。

Bluetoothと付近のデバイス

近くの端末と送受信している間だけ、Wi-Fiがなくても2台が互いを見つけて接続方法を決められるように使います。Auramyがあなたの位置を特定するためにBluetoothを使うことはありません。

ローカルネットワーク（iPhone）

近くの端末と共有している間だけ、同じネットワーク上でAuramyを使っている他のスマホを見つけて直接接続するために使います。

カメラ（iPhone）

近くの端末と共有するときに、相手のスマホのコードを読み取るためだけに使います。何も録画・保存されません。AndroidではGoogle Playサービスのスキャナがコードを読み取り、Auramyがカメラにアクセスすることはありません。

位置情報（Android 12以前）

これらのAndroidバージョンでは、アプリが独自のWi-Fiネットワークを開いたり近くのWi-Fiデバイスを探したりする前に、システムが位置情報の権限を求めます。Auramyは共通のネットワークがない状態での近くの端末との共有にのみこの権限を求め、あなたの位置を読み取ることはありません。

Face ID / Touch ID / 指紋

任意です。アプリロックをオンにしたときに、アプリのロック解除にだけ使います。システムが返すのは成功か失敗かだけで、Auramyが生体情報を受け取ったり保存したりすることはありません。

通知

任意です。バックグラウンドのバックアップが完了したことや、空き容量通知をオンにした場合に大きな空き容量を確保できることを知らせるために使います。通知はデバイス上で作成され、プッシュサーバーはありません。

バックグラウンドでの動作

アプリが画面に表示されていないときに、進行中のバックアップを続けたり、ときどき空き容量を確認したりするために使います。どちらも完全にスマホ上で動作します。

7. 位置情報データ

Auramyがあなたの位置を読み取ることはありません。ただし、写真にはカメラが記録したGPS座標が含まれている場合があります。Auramyから写真やビデオを共有すると、位置情報のメタデータはデフォルトで削除されます。位置情報もファイルと一緒に送りたい場合は、設定でオフにできます。あなた自身のGoogleドライブへのバックアップでは、常に元のファイルがそのまま保存されます。

8. 購入

Auramy ProはApp StoreまたはGoogle Playで購入します。支払いはAppleまたはGoogleが処理し、Auramyはそこからアカウントで Pro が有効かどうかだけを知らされます。開発者があなたの支払い情報を見ることはありません。

9. 保存期間と削除

  • Auramyが保存するものはすべてアプリ専用のストレージにあります。アプリを削除すると、検索インデックス、設定、保存されたサインイン情報を含め、すべてが消去されます。
  • アプリを削除すると、プライベート保管庫も削除されます。残したい写真は先に保管庫から移動してください。
  • アプリを削除せずにGoogleドライブとの接続を解除するには、設定の「サインアウト」を使ってください。myaccount.google.com/permissions でいつでもAuramyのアクセス権を取り消すこともできます。
  • バックアップした写真は、あなたがドライブで削除するまでGoogleドライブに残ります。それはあなたのアカウントにある、あなたのファイルです。
  • 共有したリンクは、7日後または共有を停止したときにドライブから削除されます。誰かがリンクからすでに保存した写真は、その人の手元に残ります。

10. 子ども

Auramyは13歳未満の子どもを対象としておらず、子どもの情報を意図的に収集することはありません。開発者は誰からも情報を収集していないため、請求に応じて削除するものはありませんが、気になることがあればご連絡ください。

11. あなたの権利

お住まいの地域によっては、GDPR（欧州）、KVKK（トルコ）、CCPA/CPRA（カリフォルニア）などの法律に基づき、あなたに関する個人データへのアクセス、訂正、エクスポート、削除などの権利がある場合があります。

開発者はあなたの個人データを保有していないため、開発者側で開示、エクスポート、消去するものはありません。デバイス上のデータはあなたが直接管理しており、アプリを削除すると消去されます。Googleドライブ内のデータは、あなたのGoogleアカウントで管理できます。それでも権利を行使したい場合やご質問がある場合は、下記の連絡先までご連絡いただければお返事します。

12. セキュリティ

Auramyは、オペレーティングシステムが提供する保護に依拠しています。アプリのサンドボックス化、暗号化されたストレージ、認証情報のためのシステムの安全な保管領域です。インターネット通信はすべてHTTPSを使い、近くの端末との転送はエンドツーエンドで暗号化され、プライベート保管庫はあなたのPINでしか生成できない鍵で暗号化されます。任意のアプリロックは、アプリの前にFace ID、Touch ID、指紋、またはパスコードを置き、アプリがバックグラウンドにある間はアプリスイッチャーでギャラリーを隠します。

完全に安全なシステムはありません。デバイスを最新の状態に保ち、パスコードで保護することが、そこにあるものを守るために最も大切なことです。

13. このポリシーの変更

このポリシーに重要な変更がある場合は、上部に新しい日付を記載した更新版をここに掲載します。変更後もアプリを使い続けることで、改定後のポリシーに同意したものとみなされます。
